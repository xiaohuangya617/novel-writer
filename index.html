快速指南

✨ 快速开始 1. 新建小说 → 2. 点击⚙配置API Key → 3. 输入指令 → Ctrl+Enter 生成

⌨️ 全局快捷键

Ctrl+Enter 发送指令生成 · Ctrl+G 续写下一章 · Ctrl+F 查找 · Ctrl+H 替换 · Ctrl+Z/Y 撤销/重做 · Ctrl+S 保存章节

🎯 精准模式

点击聊天区 🎯 按钮打开面板，勾选本章出场的角色、动作、服装。未勾选的设定不会注入 AI，大幅减少无关信息干扰。

💭 思考模式

API 调参面板可开启思考模式，AI 先内部规划再写正文，更严格遵循角色/动作/服装规范与禁用词。强度分 low / high / max 三档。注意：开启后温度等创意参数失效。

🔀 并发双版

点击聊天框旁的 ⧉ 并发双版 按钮开启（高亮），首次生成会同时产出 A/B 两个版本供对比，点击任一版本保留，另一版本自动丢弃。仅适用于全新生成（续写/重写不生效），单次生效——生成结束自动关闭。费用×2。

📝 单章摘要（v5.8）

每章生成时同请求附带 150 字摘要（时间/地点/事件/关键细节，正文末尾【摘要】标记），显示在编辑器正文下方，可手动编辑。若同请求摘要缺失/截断，可点「🔄 重新生成」用独立请求补（已加虚构文学声明，敏感内容也会如实总结）。生成新章时，前文只注入各章摘要（成本大幅降低），无摘要的章节回退注入全文。

🚀 v7 新增功能

📈 角色成长（v7.1）：AI 生成时自动提取角色成长经历，⭐当前状态优先注入，前后章成长衔接。

✍️ 续写三走向（v7.2）：点续写先弹 3 张走向卡片（主动攻略/被动转折/女主视角），选中填入消息栏再发送。

🔄 重写回填（v7.2）：点重写把原始指令回填消息栏 + 还原精准勾选，发送按钮变重写态，可回滚。

✨ 润色（v7.3）：AI 审查润色本章——红（原句）/绿（新句）高亮，低幅度修改带黄色理由；应用=直接保存解锁，取消=还原润色前正文。冲突检测改为仅手动。

🎯 创作逻辑链

系统提示：全局提示词 → 行文规范 → 角色关系图 → 角色设定 → 动作设定 → 服装设定 → 禁用词 → 世界观 → 情节主线 → 专有名词 → 输出

AI 严格遵循角色设定与动作规范，避免禁用词，保持前后文连贯。角色关系图全量注入，不受精准模式影响。

AI小说生成器 v7.4 完整说明

一、快速上手（3步）

1. 左侧面板点击「+ 新建小说」，输入书名创建

2. 点击聊天区右侧 ⚙ 按钮或顶部按钮，填入 DeepSeek API Key（需自行注册获取），点「测试连接」确认可用后「保存」

3. 在聊天框输入创作指令，按 Ctrl+Enter 或点击 ✈ 发送按钮，AI 自动生成章节

二、⌨️ 全部快捷键一览

Ctrl+Enter发送聊天指令，AI 开始生成新章节
Ctrl+G续写下一章（基于已有章节末尾）
Ctrl+F在当前章节中查找文本
Ctrl+H查找并替换文本
Ctrl+Z / Ctrl+Y撤销/重做编辑操作
Ctrl+A全选当前章节文本
Ctrl+S保存当前章节（焦点不在输入框时）

三、🎯 精准模式（v1.5 新增，v1.7 优化，v2.9 支持服装）

点击聊天区右侧 🎯 按钮打开精准设定面板，控制 AI 生文时注入哪些角色、动作和服装设定。

背景：默认全量注入角色库、动作库和服装库，大量无关设定稀释 AI 注意力。精准模式通过勾选，仅注入选中的条目。

操作：点击🎯→三列面板：左列勾选本章出场角色、中列勾选本章用到的动作、右列勾选本章出场的服装→保存。按钮变绿表示精准模式开启。

校验：至少选1个角色、动作或服装才能保存。点击「关闭精准模式」可恢复全量注入（关闭时**保留勾选**，下次开启直接沿用）。

快捷操作（v7.1）：弹窗内支持「全选角色/动作/服装」「全部取消」「🎲 随机组合」（一键抽取 1 角色+3 动作+1 服装复制剪贴板）「📋 本次组合」（复制当前勾选的动作+服装名称，清洗括号说明）。

一次性（v7.2 更新）：精准模式开启 = **下一次生文（新写/重写/续写）都是精准注入**，生成完成后自动关闭（勾选保留）。重写发起时若存在勾选会自动重新开启精准模式，按勾选精准注入。

建议：日常对话勾出场角色+「日常对话」动作；打斗勾对战双方+「打斗」；感情戏勾情侣+相关动作；每章勾选实际出现的服装。

两种模式生文对比：

设定来源非精准模式精准模式
全局提示词 🌍✅ 全量注入✅ 全量注入
行文规范 ✍️✅ 全量注入✅ 全量注入
角色关系图 🔗✅ 全量注入✅ 全量注入（不受精准影响）
角色库 👥全部角色仅勾选的角色
动作库 💪全部动作仅勾选的动作
服装库 👗全部服装仅勾选的服装
禁用词 🚫✅ 全量注入✅ 全量注入
世界观/情节/专有词 📖✅ 全量注入✅ 全量注入

四、📚 书架与章节管理

新建小说：左侧书架顶部「＋」图标或底部「＋新建小说」按钮。每本小说的数据独立存储。书架上每本小说卡片显示章节数、角色数和总字数。

切换小说：点击书架中的小说卡片即可切换，当前编辑内容会自动保存。

删除小说：点击小说卡片右侧 🗑 图标，需要二次确认。

章节列表：左下面板展示当前小说所有章节。点击章节名切换到该章；拖拽章节可重新排序；每章右侧有重命名 ✎ 和删除 🗑 按钮。

新增章节：章节列表顶部「＋」按钮，创建空白章节供手动书写。

五、✍️ 编辑器操作

◀ ▶ 按钮：切换到上一章/下一章

A+ / A-：调整编辑器字体大小（12px~24px），偏好自动记忆

🔍 查找：弹出查找栏，实时高亮所有匹配项，◀▶ 导航，支持替换单个或全部

💾 保存：手动保存当前章节到本地存储

续写：在已有最后章节的基础上，让 AI 自动生成下一章。可在聊天框输入额外指令（如"引入新角色"）来引导续写方向

重写（v7.2）：点击重写 → 把本章原始指令回填到消息栏（可见可编辑）+ 还原当前精准勾选（精准模式开启时按勾选精准注入）；**发送按钮变重写态**（警示色+脉冲）标识「发送=重写本章」，防误新建章节；切换章节/发送完成自动退出重写态。重写前自动保存快照，可用「回滚」恢复；回滚按钮仅在重写真正生成文字后才亮起。

续写（v7.2）：点击续写 → 先生成 3 个剧情走向卡片（标题+150 字大纲，注入精准角色+最新章摘要+前10章摘要+最新章开头/结尾500字+世界观+情节主线），三方向固定架构：①主动攻略（男主计谋/能力/正向手段）②被动转折（突发事件打破僵局、男主可受限但仍有办法，不引入超自然/凶杀/未铺垫的隐藏真相）③女主视角（前半段女主与核心关联人物的羁绊日常，中后段男主切入形成对照）。选中卡片 → 大纲填入消息栏（可编辑）→ Ctrl+Enter 或「续写自动」开关自动续写；走向请求失败 → toast+日志+聊天区提示，无回退动作。

润色（v7.3）：AI 审查并润色本章（审稿 API，默认 DeepSeek 思考模式）。审查三类——大幅修改（人设冲突、违背物理常识、时空混乱、不合理比喻，即使影响后文也标出，由作者后处理）、小幅修改（词语错误、逻辑小错位）、不修改（信息量零变化的措辞替换）。预览红（原句）/绿（新句）高亮，**低幅度修改带黄色理由**（字符变动比例低于「低幅度理由线」时标注，供你判断是否采纳）；正文可自由编辑、可逐条删红/绿。点「应用」→ 红绿配对去红留绿、孤立红/绿按你的选择保留 + **直接保存并解锁**（正文纯净）；点「取消」→ **完全还原润色前正文**（预览期手动删改全部作废）。

冲突检测（v7.3）：生成后不再自动检测，改为手动——点击「检查」检测定稿内容（生成初稿 → 可选润色 → 手动检测），每章省一次 API

回滚：撤销最近一次重写，恢复重写前的章节内容。仅在重写后可用

检查：调用 AI 对比前文内容与角色设定，检测外貌矛盾、时间线混乱、关系错误等潜在问题

六、💬 聊天指令区

位于页面中间的面板。输入创作指令（如「第二章，雨夜男主送女主回家，气氛暧昧」）后 Ctrl+Enter 发送。

生成时显示「✍️生成中...」，完成后章节自动保存并出现在编辑器和章节列表中。

聊天区最多保留 50 条历史记录，超出后自动移除最早的。可点击「清空记录」清除（有二次确认）。

每次生成完成后，聊天消息会显示 预估费用（按输入1元/百万token、输出2元/百万token计算）。

生成过程中可点击红色 ⏹ 停止 按钮取消当前生成。

七、📖 世界书设置（右侧面板）

📖 世界书 tab：

  • 世界观：故事发生的时代背景、地理设定、社会规则
  • 情节主线：故事的整体走向、核心冲突、关键转折
  • 专有名词：特殊词汇、人名地名、魔法体系等自定义术语及解释

🌍 全局提示 tab：

  • 全局提示词：定义 AI 的系统角色，如「你是一位擅长细腻情感的言情小说家，注重心理描写和氛围营造」
  • 行文规范：设定文风要求，如「文风细腻、多用比喻、段落简短有力」

以上所有文本框在失去焦点时自动保存。

八、👥 本书角色库

点击顶部「本书角色库」按钮打开管理面板。每个角色可设定：

  • 姓名：角色名称（必填）
  • 外貌体征：身高、发型、体型等
  • 性格：内向/外向、温柔/暴躁等
  • 服装及其他设定：常穿服饰、特殊能力、背景故事等
  • 身份关联：角色身份、与主线的关系等

角色设定在 AI 生文时作为系统提示注入。支持从「素材角色库」批量导入/导出。

九、🔗 本书关系图

点击顶部「本书关系图」打开 SVG 人物关系网络图。关系图数据会在 AI 生文时全量注入 system prompt（不受精准模式影响），以「角色关系图」段落形式出现在角色设定之前。

  • 添加关系：点击角色方块 → 在弹窗中选目标角色 + 输入关系名（如"母子""暗恋""宿敌"）→ 点添加
  • 删除关系：点击角色 → 在已有关系中点击 ✕ 删除
  • 颜色规则：同一种关系名自动分配同一种颜色，一目了然
  • 拖拽布局：可拖拽任意节点调整位置，点「重置布局」恢复方形棋盘排列；网格吸附开关可让节点对齐网格

十、🎭 素材角色库

跨小说通用的角色模板库。可新增、编辑、删除素材角色，支持 JSON 导入/导出。在本书角色库中可一键批量导入素材角色。

十一、📝 草稿本（v1.8 新增）

顶部「草稿本」按钮打开独立文本编辑器，用于临时记录灵感、随笔、情节构思。内容存储在浏览器本地，点击「保存」生效。备份时会一并导出。

十二、💪 全局动作库

定义通用动作描写规范。每个动作包含：动作要领、台词运用、描写建议。AI 生成时会严格遵循这些规则来描写动作场景（如"打斗动作：注重速度和力量感，短句快速切换"）。支持 JSON 导入/导出。

十三、🚫 本书禁用词

添加不希望 AI 使用的词语或短语（如某些现代词汇、人名、俗语）。AI 在生成时会收到警告，尽力避免使用这些词汇。

十四、⚙️ API 调参（v7.1 起三页签）

点击聊天区右侧 ⚙ 按钮打开设置，含三个页签：

  • ✍️ 正文 API：正文生成配置——API 地址/Key/模型（默认 DeepSeek deepseek-v4-flash）、温度、Top-p、重复惩罚、最大长度、频率/存在惩罚、上下文章节数、停止词、思考模式开关、推理强度（low/high/max），以及两个自动发送开关（见下）
  • 🔍 审稿 API（v7.1，v7.3 完善）：润色审查配置——地址/Key/模型（默认 DeepSeek 审稿，同人内容宽松）、🧠 推理强度（low/high/max，默认 max）、✂️ 低幅度理由线（20%~90%，默认 50%：字符变动比例低于此线的修改会标注黄色理由）、最大长度（默认 50000）；DeepSeek 默认思考模式，无温度参数
  • 🎨 生图 API：规划中（仅 EXE 版实装），灰显占位

💭 思考模式：AI 在写正文前先内部"打草稿"——回顾前文、对照角色库/动作库/服装库/禁用词检查一致性，再落笔。推理强度三档 low/high/max，越高思考越深入、token 越大速度越慢；开启后温度等创意参数失效。

🧭 续写自动（v7.2）：开启后选中续写走向卡片即自动续写；关闭（默认）则填入消息栏待手动 Ctrl+Enter 发送。

🔄 重写自动发送（v7.2）：开启后点击重写回填原始指令即自动执行；关闭（默认）则回填后待手动发送。

点击「测试连接」验证 API 可用性后再保存（正文/审稿各自测试）。

十五、💾 备份与导出

备份：导出包含所有小说、角色、动作库、API 配置的完整 JSON 文件。建议定期备份。

恢复：导入之前导出的备份 JSON，会覆盖当前全部数据，请谨慎操作。

导出（v6.4）：顶部「导出」按钮点击后弹出选择——导出全书（当前小说的全部章节为 TXT）/ 导出本章（仅当前编辑的章节为 TXT）。

十六、📈 角色成长库（v7.1）

角色可以随剧情成长。AI 生成新章时，若正文包含角色成长情节，会返回「【成长】」标记段；系统自动分离提取为成长经历条目（如「第5章：千岁首次主动靠近男主」），追加到该角色的成长库。

  • 查看/编辑：本书角色库 → 角色详情 → 「成长经历」列表，可新增、编辑、删除条目；删除角色/章节时成长条目级联清理
  • 注入机制：生成时注入角色设定 + 成长经历——⭐ 标记最新状态作为「当前状态」优先注入，其余成长经历按权重次之（用户消息＞最新成长状态＞角色库人设）；前后章节成长状态自动衔接
  • 标题自动补章号：成长条目无章号时自动补当前章节号，便于追溯
  • 调试：成长解析过程有 toast 提示（「成长调试：AI输出段=有/无|解析=N条」）

十七、🛡️ 数据与安全

存储位置：所有数据存储在浏览器 localStorage 中，不会上传到任何服务器。清除浏览器数据会导致数据丢失。

容量上限：约 5MB，顶部实时显示使用量。超过 80% 时会变橙色警告，建议及时导出备份。

自动保存：每 30 秒自动保存一次；切换章节、切换小说、关闭页面时也会自动保存。

API Key 安全：仅存储在本地浏览器，仅用于调用 DeepSeek API，不会发送到其他地方。
