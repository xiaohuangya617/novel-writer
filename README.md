## 简介

AI小说生成器是一款完全运行在浏览器中的小说创作辅助工具。你只需要提供创作指令，AI 便会根据你设定的世界观、角色、动作规范等生成连贯的章节内容。所有数据均存储在本地，无需服务器，保护你的创作隐私。

---

## 🚀 快速开始

### 1. 创建小说
左侧面板点击「**+ 新建小说**」，输入书名即可创建。

### 2. 配置 API Key
点击聊天区右侧的 **⚙** 按钮，填入 DeepSeek API Key：
- API 地址：`https://api.deepseek.com/chat/completions`
- 模型：`deepseek-v4-flash`（或其他 DeepSeek 模型）
- 点击「**测试连接**」确认可用后「**保存**」

> ⚠️ API Key 仅存储在浏览器本地，不会上传到任何服务器。

### 3. 生成章节
在聊天框输入创作指令（如：*"雨夜，男主送女主回家，气氛暧昧"*），按 **Ctrl+Enter** 或点击 ✈ 发送按钮，AI 自动生成章节。

## ✨ 核心功能

### 🎯 精准模式
- 勾选本章实际出场的**角色**、用到的**动作**和**服装**
- 未勾选的设定不会注入 AI，大幅减少无关信息干扰
- 让 AI 专注于当前场景，生成更精准的内容

### 🔗 关系图谱
- 可视化展示角色之间的关系网络
- 拖拽节点调整布局，自由添加/删除关系
- AI 生文时自动遵循角色关系，保持人物逻辑一致

### 📚 多书管理
- 支持同时创作多本小说，书架独立存储
- 章节列表支持**拖拽排序**，灵活调整叙事顺序
- 每本书独立维护角色库、禁用词、世界观等

### 💪 动作 & 服装库
- 自定义动作规范（动作要领、台词运用、描写建议）
- 自定义服装细节（款式、描写建议）
- AI 严格遵循设定，保持描写风格统一

### 📝 单章摘要（v4.5）
- 每章生成时自动附带 **150 字摘要**（时间/地点/事件/关键细节）
- 摘要显示在编辑器正文下方，**可手动编辑**
- 前文仅注入各章摘要，**大幅降低 token 消耗**
- 无摘要的章节自动回退注入全文

### 🔀 并发双版（v4.5）
- 点击聊天框旁的 **⧉** 按钮开启（单次生效）
- 首次生成会同时产出 **A/B 两个版本**供对比
- 点击任一版本保留，另一版本自动丢弃
- 仅适用于**首次生成**，续写/重写不受影响
- ⚠️ 费用约为单版 ×2

### 🧠 思考模式
- AI 在写正文前先内部"打草稿"——回顾前文、对照角色库/动作库/服装库/禁用词检查一致性，再落笔
- 对长篇小说保持连贯性非常有帮助
- 推理强度三档：**low / high / max**（默认 high）
- ⚠️ 思考模式开启后，温度/Top-p 等创意参数失效

### 🔍 冲突检测
- AI 自动检查章节中的潜在矛盾
- 检测范围：角色外貌前后矛盾、性格突变、时间线混乱、关系错误、动作/服装描写与规范不符等

### 💾 本地存储 & 备份
- 所有数据存储在浏览器 localStorage，**不上传任何服务器**
- 支持一键**备份/恢复**全部数据
- 导出全书 / 导出本章为 TXT 文件

### 🔔 页签提醒
- 生成完成时页签自动闪烁，切回页面即停止
- 无需系统通知权限，双击 HTML 文件也能生效

## ⌨️ 快捷键一览

| 快捷键 | 功能 |
|--------|------|
| **Ctrl+Enter** | 发送聊天指令，AI 开始生成新章节 |
| **Ctrl+G** | 续写下一章（基于已有章节末尾） |
| **Ctrl+F** | 在当前章节中查找文本 |
| **Ctrl+H** | 查找并替换文本 |
| **Ctrl+Z / Ctrl+Y** | 撤销/重做编辑操作 |
| **Ctrl+A** | 全选当前章节文本 |
| **Ctrl+S** | 保存当前章节 |
| **Esc** | 关闭当前打开的模态框 / 查找栏 |

## 🛡️ 数据安全

| 项目 | 说明 |
|------|------|
| **存储位置** | 浏览器 localStorage，不上传任何服务器 |
| **API Key** | 仅保存在本地，仅用于调用 DeepSeek API |
| **数据导出** | 支持完整备份导出（JSON 格式） |
| **容量上限** | 约 5MB，顶部实时显示使用量 |
| ⚠️ **警告** | 清除浏览器数据会导致所有创作内容丢失，请定期点击「**备份**」导出 |
