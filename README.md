## 简介

AI小说生成器是一款**完全运行在浏览器中的小说创作辅助工具**。你只需要提供创作指令，AI 便会根据你设定的世界观、角色、动作规范等生成连贯的章节内容。所有数据均存储在浏览器本地，无需服务器，保护你的创作隐私。

**当前版本 v7.4**：草稿本 5 页签 · 4 库宽度记忆 · 关系图导出 · 复制书籍 · 素材库导入导出搜索（详见下方功能说明）；延续 v7.3 的润色审查、冲突检测及此前全部稳定功能。

## 🚀 快速开始

### 方式 A：在线使用（推荐）

点击顶部「**在线使用**」徽章，或访问 👉 **https://xiaohuangya617.github.io/novel-writer/** ，浏览器直接打开即用，无需下载安装。

### 方式 B：本地文件

下载 `AI小说生成器7.4.html` 单文件，双击用浏览器打开即可，零依赖、免安装、可离线使用。

> 两种方式功能完全一致，数据各自独立存储在对应浏览器环境（在线版与本地版数据互不干扰）。

### 1. 创建小说
左侧面板点击「**+ 新建小说**」，输入书名即可创建。

### 2. 配置 API Key
点击聊天区右侧的 **⚙** 按钮，填入 DeepSeek API Key：
- API 地址：`https://api.deepseek.com/chat/completions`
- 模型：`deepseek-v4-flash`（或其他 DeepSeek 模型）
- 点击「**测试连接**」确认可用后「**保存**」

> ⚠️ API Key 仅存储在浏览器本地，不会上传到任何服务器。

### 3. 生成章节
在聊天框输入创作指令（如：*"雨夜，男主送女主回家，气氛暧昧"*），按 **Ctrl+Enter** 或点击 ✈ 发送按钮，AI 自动生成章节。

## ✨ 核心功能

### 🎯 精准模式
- 勾选本章实际出场的**角色**、用到的**动作**和**服装**
- 未勾选的设定不会注入 AI，大幅减少无关信息干扰
- 让 AI 专注于当前场景，生成更精准的内容
- 删除角色/动作/服装后自动同步清理精准勾选，存量无效勾选自动修复
- 快捷操作：全选/全部取消、🎲 随机组合（1角色+3动作+1服装复制剪贴板）、📋 本次组合；关闭时保留勾选
- **v7.2 起**：精准模式开启 = 下一次生文（新写/重写/续写）都是精准注入，生成后自动关闭（勾选保留）

### 📈 角色成长（v7.1）
- AI 生成新章时自动提取「【成长】」标记段，分离为角色成长经历条目（如「第5章：千岁首次主动靠近男主」）
- ⭐ 最新成长状态作为「当前状态」优先注入，其余成长经历按权重注入（用户消息＞最新成长＞角色库人设）
- 前后章成长状态自动衔接；角色/章节删除时成长条目级联清理

### ✍️ 续写三走向（v7.2）
- 点续写先生成 3 张剧情走向卡片（标题+150 字大纲），注入精准角色+最新章摘要+前10章摘要+最新章开头/结尾500字+世界观+情节主线
- 三方向固定架构：①**主动攻略**（男主计谋/能力/正向手段）②**被动转折**（突发事件破局、男主可受限但仍有办法，不引入超自然/凶杀/未铺垫的隐藏真相）③**女主视角**（前半段与核心关联人物的羁绊日常，中后段男主切入形成对照）
- 选中卡片 → 大纲填入消息栏（可编辑）→ 手动发送或「续写自动」开关自动续写；失败 toast+日志+聊天区提示，无回退动作

### 🔄 重写回填（v7.2）
- 点重写 → 原始指令回填消息栏（可见可编辑）+ 还原当前精准勾选（开启则精准注入）
- 发送按钮变**重写态**（警示色+脉冲）标识「发送=重写本章」，防误新建；切章节/发送完成自动退出
- 重写前自动存快照，可回滚；回滚按钮仅在重写真正生成后才亮起

### 🗂️ 草稿本 5 页签（v7.4）
- 5 个独立页签记录灵感/随笔，切页自动保存，非空页带小圆点提示

### 📐 4 库编辑栏宽度记忆（v7.4）
- 4 库（本书/素材角色、动作、服装）编辑区与编辑框可拖拽调宽，**自动记忆、重启保持**，各库独立
- 编辑栏标题右侧「保存布局」按钮显式保存

### 🖼️ 关系图导出（v7.4）
- 一键导出 PNG（2x 高清、暗色背景、含区域），无角色时提示不生成空图

### 📑 复制书籍（v7.4）
- 一键完整复制书籍（章节/角色/关系/聊天/设定/精准勾选/关系图布局），副本内 id 自动重映射，默认名「原书名-副本」

### 🔍 素材库导入导出搜索（v7.4）
- 批量导入/导出角色弹窗支持按名称搜索 + 一键清空

### ✨ 润色审查（v7.3）
- AI 审查并润色本章（审稿 API，默认 DeepSeek 思考模式，独立于正文 API 配置）
- 审查三类：**大幅修改**（人设冲突/违背物理常识/时空混乱/不合理比喻，即使影响后文也标出）、**小幅修改**（词语错误/逻辑小错位）、**不修改**（信息量零变化的措辞替换）
- 预览红（原句）/绿（新句）高亮；**低幅度修改带黄色理由**（「低幅度理由线」滑块 20%~90% 默认 50%）；正文可自由编辑、可逐条删红/绿
- **应用** = 红绿配对去红留绿、孤立红/绿按你的选择保留 + 直接保存解锁（正文纯净）；**取消** = 完全还原润色前正文
- 审稿页签：推理强度（low/high/max，默认 max）+ 低幅度理由线 + 最大长度（50000）

### ⚙️ API 三页签（v7.1）
- **正文 API**：正文生成配置（思考模式/推理强度/续写自动/重写自动开关等）
- **审稿 API**：润色审查配置（DeepSeek 默认思考模式、推理强度、低幅度理由线、最大长度 50000）
- **生图 API**：规划中（仅 EXE 版实装，灰显占位）

### 🎲 随机组合
- 精准模式弹窗内一键**随机抽取 1 名角色 + 3 个动作 + 1 套服装**（动作不重复）
- 组合如 `小明+奔雷掌+火焰腿+霹雳刀+金丝甲`，**自动复制到剪贴板**，右下角同步提示
- 素材不足（角色空/动作不足 3 个/服装空）时给出明确提示，不生成无效组合

### 📜 日志
- 侧栏新增「📜 日志」页签，记录**右下角全部提示历史**（含 HH:MM:SS 时间戳）
- 持久化到本地，重启保留；**最多 30 条**，超出自动清空最早的
- 完整备份/恢复**包含日志**，旧备份（无日志字段）兼容跳过

### 🔗 关系图谱
- 可视化展示角色之间的关系网络（方形布局 + 区域分区，一目了然）
- 拖拽节点调整布局，自由添加/删除关系，关系颜色自定义
- AI 生文时自动遵循角色关系，双向关系分别注入，保持人物逻辑一致
- **关系全生命周期保护**：编辑角色、素材库导入/导出、JSON 导入、跨书迁移均不丢失关系
- **v7.3 起关系"无脑带走"**：导出/导入时关系不再因目标角色未同批选中而被过滤——集合内的自动重映射新 ID，集合外的保留原值，跨书续写（如「新设→暮年」）时关系完整继承

### 📚 多书管理
- 支持同时创作多本小说，书架独立存储
- 章节列表支持**拖拽排序**，灵活调整叙事顺序
- 每本书独立维护角色库、禁用词、世界观等
- 正章/间章切换：间章不占正文章号，独立计数

### 💪 动作 & 服装库
- 自定义动作规范（动作要领、台词运用、描写建议）
- 自定义服装细节（款式、描写建议）
- AI 严格遵循设定，保持描写风格统一
- 支持全局素材库 JSON 导入/导出、角色批量导入/导出（**关系一并保留**），跨书复用

### 📝 单章摘要
- 每章生成时自动附带 **150 字摘要**（时间/地点/事件/关键细节）
- 摘要显示在编辑器正文下方，**可手动编辑**
- 前文仅注入各章摘要，**大幅降低 token 消耗**；无摘要章节自动回退注入全文
- **重写章节时自动保留已有摘要**（AI 未输出新摘要时不清空）

### 🔀 并发双版
- 点击聊天框旁的 **⧉** 按钮开启（单次生效）
- 首次生成会同时产出 **A/B 两个版本**供对比
- 点击任一版本保留，另一版本自动丢弃；单版失败时自动保留成功版本
- 仅适用于**首次生成**，续写/重写不受影响
- 无 API Key 时挂起待生成任务，配置后自动重试
- ⚠️ 费用约为单版 ×2

### 🧠 思考模式
- AI 在写正文前先内部"打草稿"——回顾前文、对照角色库/动作库/服装库/禁用词检查一致性，再落笔
- 对长篇小说保持连贯性非常有帮助
- 推理强度三档：**low / high / max**（默认 high）
- ⚠️ 思考模式开启后，温度/Top-p 等创意参数失效

### 🔍 冲突检测
- AI 检查章节中的潜在矛盾：角色外貌前后矛盾、性格突变、时间线混乱、关系错误、动作/服装描写与规范不符等
- **v7.3 起改为仅手动检测**：生成（初稿）→ 可选润色 → 点击「检查」手动检测定稿内容（生成后不再自动检测，每章省一次 API）- **检测进行中编辑正文，在途结果自动作废**（快照+版本号双校验，防旧结果覆盖新内容）
- 编辑完成后旧结果**保留**供参考，点击「**重新检测**」即可更新
- 手动检测/摘要生成**防重复发起**，避免网络慢时重复点击浪费 API 费用
- 冲突检测/摘要请求均有超时保护（30 秒 / 60 秒），绝不永久卡"检查中"

### 🔒 生成期编辑锁定
- 生成、续写、重写期间，正文与摘要编辑、保存、重写、续写、冲突检测、**查找替换、回滚**全部锁定，顶部显示锁定横幅
- 停止、完成或失败后自动解锁；停止后立刻重新生成不会被旧任务误解锁
- 杜绝"AI 返回后覆盖用户在等待期间输入的内容"的数据丢失问题

### 💾 本地存储 & 备份
- 所有数据存储在浏览器 localStorage，**不上传任何服务器**
- 一键**备份/恢复**全部数据（JSON），恢复时校验版本兼容性，并自动修复存量数据
- 保存失败时**显式提示**（章节/双版/备份/API 配置），绝不"假成功"
- 导出合并为一键选择：导出全书 TXT / 导出本章 TXT / 完整备份 JSON / 素材库 JSON

### 🔔 页签提醒
- 生成完成时页签自动闪烁（✅ 成功 / ❌ 失败图标+标题），切回页面即停止

### 📝 素材草稿本
- 独立草稿本记录灵感、大纲、素材，随备份一并导出/恢复

## ⌨️ 快捷键一览

| 快捷键 | 功能 |
|--------|------|
| **Ctrl+Enter** | 发送聊天指令，AI 开始生成新章节 |
| **Ctrl+G** | 续写下一章（基于已有章节末尾） |
| **Ctrl+F** | 在当前章节中查找文本 |
| **Ctrl+H** | 查找并替换文本 |
| **Ctrl+Z / Ctrl+Y** | 撤销/重做编辑操作 |
| **Ctrl+A** | 全选当前章节文本 |
| **Ctrl+S** | 保存当前章节 |
| **Esc** | 关闭当前打开的模态框 / 查找栏 |

## 🛡️ 数据安全

| 项目 | 说明 |
|------|------|
| **存储位置** | 浏览器 localStorage，不上传任何服务器 |
| **API Key** | 仅保存在本地，仅用于调用 DeepSeek API |
| **数据导出** | 支持完整备份导出（JSON 格式，含版本号） |
| **容量上限** | 约 5~10MB（浏览器配额），顶部实时显示使用量 |
| ⚠️ **警告** | 清除浏览器数据会导致所有创作内容丢失，请定期点击「**备份**」导出 |
