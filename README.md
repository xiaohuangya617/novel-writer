## 简介

AI小说生成器是一款**完全运行在浏览器中的小说创作辅助工具**。你只需提供创作指令，AI 便会根据你设定的世界观、角色、动作规范等生成连贯的章节内容。所有数据均存储在浏览器本地，无需服务器，保护你的创作隐私。

**当前版本 v7.9**：角色试演 · 批量标签 · 峰谷计价 · 日志实时小面板；延续 v7.8 吐槽点评、v7.7 标签系统及此前全部稳定功能。

## 🚀 快速开始

### 方式 A：在线使用（推荐）

点击顶部「**在线使用**」徽章，或访问 👉 **https://xiaohuangya617.github.io/novel-writer/** ，浏览器直接打开即用，无需安装。

### 方式 B：本地文件

下载 `AI小说生成器7.9.html` 单文件，双击用浏览器打开即可，零依赖、免安装、可离线使用。

> 两种方式功能完全一致，数据各自独立存储在对应浏览器环境，互不干扰。

### 1. 创建小说
左侧面板点击「**+ 新建小说**」，输入书名即可创建。

### 2. 配置 API Key
点击聊天区右侧的 **⚙** 按钮，填入 DeepSeek API Key：
- API 地址：`https://api.deepseek.com/chat/completions`
- 模型：`deepseek-v4-flash`（或其他 DeepSeek 模型）
- 点击「**测试连接**」确认可用后「**保存**」
- 计费按 **DeepSeek 峰谷定价**：高峰时段（北京时间 9:00-12:00、14:00-18:00）价格为空闲时段的 2 倍，flash/pro 模型自动按模型名分档计价

> ⚠️ API Key 仅存储在浏览器本地，不会上传到任何服务器。

### 3. 生成章节
在聊天框输入创作指令（如：*"雨夜，男主送女主回家，气氛暧昧"*），按 **Ctrl+Enter** 或点击 ✈ 发送，AI 自动生成章节。

## ✨ 核心功能

### 🎭 角色试演（v7.9）
- **A/B 双角色 AI 对话扮演**：从角色库挑选 2 名角色，AI 以角色身份实时对话
- 候选角色搜索 + 滚动浏览；场景设定框注入「当前对话场景及设定」
- 最多 **10 轮**对话，首轮锁定场景与选角；括号神情/动作（`（）`）必填，拟声/心理可选
- 情绪与特殊设定**跨轮延续**；结束自动生成**追加式互动摘要**
- 扮演独立计费（默认 flash），金额计入本书统计；切章/切书/重置自动退出

### 🏷️ 批量标签（v7.9）
- 三库（本书角色库/素材角色库/全局服装库）「**批量标签**」：输入标签名 + 勾选目标 + 确定，批量加高亮；输入 `-标签名` 批量取消
- 预设标签（含**原设/自设**）可批量加/删高亮，但标签名不可被批量删除（仅「新增预设标签」的 `-号` 可删）
- **原设 ↔ 自设 互斥**：高亮一个自动熄灭另一个；其他标签可多选共存
- 弹窗带搜索、全选/全不选、已勾选计数；搜索过滤后勾选不丢
- 老书存量标签升级后自动统一取消高亮（一次性迁移）
- **说明**：标签目前仅用于筛选/高亮，暂未注入 AI 上下文，等待后续版本更新

### ⏱ 峰谷计价（v7.9）
- 按 DeepSeek 官方峰谷定价实时计费：**高峰时段**（北京 9:00-12:00、14:00-18:00）价格为**空闲时段的 2 倍**
- flash / pro 按**模型名自动分档**，缓存命中/未命中/输出分开计算
- 所有计费行为（生文/双版/润色/吐槽/检查/摘要/扮演）均按实时时段计价

### 📊 日志实时小面板（v7.9）
- 日志页签下方固定小面板，实时显示：**当前日期时间、计费时段（高峰/空闲）、本次消费金额、本次使用时长、本次输入字数、本次生成字数**
- 输入字数 = 本次运行发送的指令/扮演台词累计；生成字数 = 本次运行新增章节正文字数（重写替换/续写追加不计）
- 1 秒自动刷新，暗色毛玻璃风格与主题一致

### 💬 吐槽点评（v7.8）
- 模拟读者/编辑/粉丝等 **10 个内置角色**点评本章，每次随机 3 个
- 生文链路摘要与角色成长三段分离展示

### 🏷️ 标签系统（v7.7）
- 角色与服装库支持**预设标签 + 自定义标签**，名称 + 标签**联合查重**
- 标签用于筛选/高亮分类，**暂未注入 AI 上下文**，等待后续版本更新

### 📊 写作统计看板（v7.6）
- 字数/时间/金额统计看板 + TOP 排行（本书/全局）
- **全局金额删书不清**：累计消耗按所有书籍（含已删除）统计，不随重置清零
- 设置面板合并世界观名词与主线大纲

### 📐 四库编辑体验（v7.5）
- 四库编辑栏尺寸记忆 + 复制书籍（副本独立编辑，自动回到码字中）

### 🗂️ 草稿本 5 页签（v7.4）
- 5 个独立页签记录灵感/随笔，切页自动保存，非空页带圆点提示

### 🎯 精准模式
- 勾选本章出场的**角色**、用到的**动作**和**服装**，未勾选的设定不注入 AI，减少无关干扰
- 删除设定项后自动清理无效勾选；全选/全取消、🎲 随机组合（1角色+3动作+1服装）、📋 本次组合
- **v7.2 起**：开启 = 下一次生文（新写/重写/续写）精准注入，生成后自动关闭（勾选保留）

### 📈 角色成长（v7.1）
- AI 自动提取「【成长】」段为角色成长经历；最新成长作为「当前状态」优先注入
- 前后章成长自动衔接；角色/章节删除时成长条目级联清理

### ✍️ 续写三走向（v7.2）
- 续写先生成 3 张走向卡片（标题+150 字大纲），三方向固定架构：**主动攻略 / 被动转折 / 女主视角**
- 选中卡片 → 大纲填入消息栏（可编辑）→ 手动发送或「续写自动」自动续写

### 🔄 重写回填（v7.2）
- 重写 → 原始指令回填消息栏 + 还原精准勾选；发送按钮变**重写态**（警示色+脉冲）防误新建
- 重写前自动存快照可回滚；回滚按钮仅在重写生成后亮起

### 🖼️ 关系图导出（v7.4）
- 一键导出 PNG（2x 高清、暗色背景、含区域）

### 📑 复制书籍（v7.4）
- 一键完整复制书籍（章节/角色/关系/聊天/设定/勾选/布局），id 自动重映射

### ✨ 润色审查（v7.3）
- AI 审查并润色本章（审稿 API，默认 DeepSeek 思考模式，独立配置）
- 审查三类：**大幅修改**（人设冲突/常识违背/时空混乱等）、**小幅修改**（措辞/逻辑小错）、**不修改**
- 红（原句）/绿（新句）高亮，低幅度修改带黄色理由；正文可编辑、逐条删红/绿
- **应用** = 去红留绿 + 保存解锁；**取消** = 完全还原

### ⚙️ API 多页签
- **正文 API**：正文生成配置（思考模式/推理强度/续写自动/重写自动）
- **审稿 API**：润色审查配置（模型/推理强度/低幅度理由线/最大长度）
- **扮演 API**：角色试演配置（温度/最大长度/轮数/人设与语气开关）
- **生图 API**：规划中（仅 EXE 版实装，灰显占位）

### 🔗 关系图谱
- 可视化角色关系网络，拖拽调整布局，关系颜色自定义
- AI 生文自动遵循角色关系；编辑/导入/迁移均不丢关系
- **v7.3 起关系"无脑带走"**：导出/导入时集合内自动重映射新 ID，集合外保留原值，跨书续写关系完整继承

### 📚 多书管理
- 多书独立存储，章节列表**拖拽排序**，正章/间章切换（间章独立计数）

### 💪 动作 & 服装库
- 自定义动作规范与服装细节，AI 严格遵循设定
- 全局素材库 JSON 导入/导出、角色批量导入/导出（**关系一并保留**）

### 📝 单章摘要
- 每章自动附带 **150 字摘要**（时间/地点/事件/细节），可手动编辑
- 前文仅注入各章摘要，**大幅降低 token 消耗**；无摘要章节自动回退全文
- 重写章节时自动保留已有摘要

### 🔀 并发双版
- 一次生成 **A/B 两版**供对比，选一保留；单版失败自动保留成功版
- 仅首次生成生效；无 Key 时挂起待生成，配置后自动重试；⚠️ 费用约单版 ×2

### 🔍 冲突检测
- AI 检查章节矛盾（人设/性格/时间线/关系/动作服装不符等）
- **v7.3 起仅手动检测**：生成 → 可选润色 → 手动「检查」定稿（每章省一次 API）
- 编辑后旧结果保留，可「重新检测」更新；防重复发起；30/60 秒超时保护

### 🔒 生成期编辑锁定
- 生成/续写/重写期间，正文编辑、查找替换、回滚等全部锁定并显示横幅
- 停止/完成/失败后自动解锁，杜绝"AI 返回覆盖等待期间输入"的数据丢失

### 💾 本地存储 & 备份
- 数据全部在浏览器 localStorage，**不上传任何服务器**
- 一键备份/恢复 JSON，兼容 **2.6~7.9 全版本**存档，自动修复存量数据
- 保存失败显式提示，绝不"假成功"；导出：全书 TXT / 本章 TXT / 完整备份 / 素材库 JSON

### 📜 日志
- 侧栏「📜 日志」页签记录全部提示历史（HH:MM:SS 时间戳），最多 50 条，固定高度可滚动
- 下方为**实时统计小面板**；完整备份/恢复包含日志，旧备份兼容跳过

### 🔔 页签提醒
- 生成完成时页签闪烁（✅/❌ 图标+标题），切回页面即停止

| 快捷键 | 功能 |
|--------|------|
| **Ctrl+Enter** | 发送聊天指令生成新章节（角色试演输入框同样生效） |

| **Ctrl+F / Ctrl+H** | 查找 / 查找替换 |

| **Ctrl+A** | 全选当前章节 |
| **Ctrl+S** | 保存当前章节 |
| **Esc** | 关闭模态框 / 查找栏 |

|------|------|
