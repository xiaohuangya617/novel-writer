一个面向 PC 浏览器的 AI 小说创作工具。它把 DeepSeek 等兼容聊天补全接口接入书籍、章节、角色资料和创作流程：模型负责生成与分析文本，网页负责管理作品、组装上下文、保存资料、回写摘要和角色成长。

**当前版本：8.7** · [在线使用](https://xiaohuangya617.github.io/novel-writer/) · [查看源代码](https://github.com/xiaohuangya617/novel-writer)

## 快速开始

1. 打开[在线版本](https://xiaohuangya617.github.io/novel-writer/)，或下载仓库中的 `index.html` 后用浏览器打开。单文件版本也可以直接双击 `AI小说生成器8.7.html` 使用。
2. 点击右上角“API 调参”，填写 API 地址、API Key 和模型，测试连接后保存。默认地址为 `https://api.deepseek.com/chat/completions`，也支持兼容接口。
3. 新建书籍，填写世界观、主线大纲、写作提示，并按需维护角色、动作、服装和关系资料。
4. 在消息框输入本章要求后发送；正文完成后，程序会继续整理章节摘要和角色成长。`Ctrl+Enter` 可以快速发送。
5. 定期点击“备份”导出 JSON。清除浏览器数据会删除本地作品和配置。

API 请求产生的费用由用户填写的服务商账户承担。页面中的费用是根据接口返回用量和当前计价设置计算的估算值。

## 创作链

### 正文创作

固定设定、主线、近期摘要、角色成长和本次消息会按顺序组装进请求。正文生成后，程序会独立整理摘要和成长资料，并将结果回写到当前作品。

### 续写与走向

- **三条续写走向**：根据当前作品生成三张方向卡片；选择后只回填消息框，由用户确认后再生成正文。
- **连发多章**：设定目标后连续生成多章，并在每章完成后更新摘要和角色成长。
- **重写回填**：根据指令重写当前章节，支持精准注入资料和回滚。
- **并发双版**：同时生成 A/B 两版正文，选择保留的版本。

### 辅助创作

- **检测**：四档评级、正文标黄、点击定位和修改建议，手动触发以节省 API 调用。
- **润色**：按语义审查修改建议，显示红绿差异和修改理由，可逐条应用或取消。
- **吐槽点评**：由读者、编辑、作家、粉丝和喷子等虚拟角色点评当前章节，并展示原文引用。
- **角色试演**：支持 A/B 双角色对话、场景设定和跨轮情绪延续。
- **角色成长**：自动提取章节经历，最新状态优先注入后续创作。

## 主要功能

- 多书管理、独立书架、章节拖拽排序和草稿恢复。
- 精准模式：只注入勾选的角色、动作和服装，减少无关设定干扰。
- 角色关系图、全局角色素材库、动作库、服装库和全局禁用词。
- 一键起书：按模板和平台要求生成书名、世界观、主线大纲和第一章。
- 上下文预算条、发送后真实 usage 显示、缓存分区和稳定段前置。
- 审稿参数模式、思考模式、推理强度、温度、Top-p 和重复惩罚等参数。
- 写作统计、费用统计、日志、页签提醒和隐藏模式。
- 正文、全书、本章和角色/动作/服装资料导出。
- 浏览器单文件版本与 Electron EXE 版本共用作品数据结构，适合轻量使用和桌面端重度使用。

## PC 与 Android 存档联动

两端通过 JSON 项目存档交换作品资料。当前是**安卓端导出 HTML 存档，PC 端导入**的兼容路径：

1. 在 Android App 打开右上角“存档”，选择“导出/分享项目存档（HTML）”。
2. 将导出的 JSON 文件传到 PC。
3. 在 PC 网页版点击“恢复”，选择该 JSON 文件，确认后导入作品。

Android 的 HTML 存档包含书籍、章节、角色、动作、服装、禁用词和必要的创作资料，API Key 不会写入存档。PC 导入后可以继续编辑和生成；PC 端的额外配置会按网页版规则处理。

两种存档用途不同：

| 存档 | 用途 | API Key | 兼容范围 |
| --- | --- | --- | --- |
| Android App 存档 | 恢复 Android App 的完整状态 | 不包含，Key 保存在 Android Keystore | 仅 Android App 接受 |
| Android HTML 存档 | 把作品资料交给 PC 网页版 | 不包含 | PC 网页版导入 |
| PC 网页版完整备份 | 恢复 PC 端全部本地数据 | 可能包含明文 Key，导出前会警告 | PC 网页版导入 |

PC 网页版完整备份不能直接作为 Android App 存档恢复。需要从 Android 回到 PC 时，请使用 Android 的“HTML 项目存档”选项；需要在 Android 上恢复时，请使用 Android 自己导出的“App 项目存档”。

导入存档会覆盖当前端的作品和相关资料，操作前请先导出当前端备份。安卓端的字号、走向策略、开发者 Prompt 等 App 专用设置不会写入 HTML 存档；PC 端的 API Key、日志、统计和其他浏览器专用数据也不会随 Android HTML 存档传递。

## 数据与安全

| 项目 | 说明 |
| --- | --- |
| 本地数据 | 作品、章节、设定和素材默认保存在浏览器 `localStorage`，不会上传到本项目自有服务器。 |
| AI 请求 | 使用生成、摘要、检测、润色、吐槽和试演时，相关正文、设定和请求内容会发送到你配置的 API 服务商。 |
| API Key | 网页版保存在本地浏览器配置中；PC 完整备份可能包含明文 Key，导出时会弹出警告。 |
| 存储容量 | 浏览器本地存储通常约为 5MB，页面顶部会显示使用量；接近上限时应及时备份。 |
| 数据丢失 | 清除浏览器缓存、站点数据或误删备份文件都可能导致本地作品丢失。 |

请不要把包含 API Key 的 PC 完整备份上传到网盘、提交到公开仓库，或通过聊天工具转发给他人。
