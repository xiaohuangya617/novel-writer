## 🚀 快速开始

- **在线使用**：点击顶部徽章或访问 https://xiaohuangya617.github.io/novel-writer/ 即开即用
- **本地文件**：下载 `AI小说生成器8.6.html` 双击打开；或使用整合版 zip 内的 EXE
- **配置**：⚙ 填入 DeepSeek API Key（`https://api.deepseek.com/chat/completions`）→ 测试连接 → 保存；Key 仅存本地
- **创作**：聊天框输入指令，Ctrl+Enter 生成章节；计费按 DeepSeek 峰谷定价自动计算

## ✨ 核心功能

**创作主链路**
- ⚡ **一键起书**：模板/平台/去AI味/网文排版，从零生成书名+世界观+大纲+第一章
- 📚 **连发多章**：目标贯穿每章，全程锁与停止可靠
- 🔁 **续写三走向**：主动攻略 / 被动转折 / 女主视角，卡片选择
- 🔄 **重写回填 + 回滚**：指令回填精准注入，一键还原
- ⧉ **并发双版**：A/B 两版择优保留

**辅助创作**
- 🔍 **检测**：四档评级 + 正文标黄 + 点击定位 + 修改建议（手动触发，省 API）
- ✨ **润色**：语义级审查，红绿高亮 + 修改理由，应用/取消
- 💬 **吐槽点评**：3 位虚拟读者/编辑点评本章（带原文引用）
- 🎭 **角色试演**：A/B 双角色 AI 对话，场景设定 + 跨轮情绪延续
- 📈 **角色成长**：自动提取经历，最新状态优先注入

**智能注入（v8.5/v8.6）**
- 精准模式：仅注入勾选角色/动作/服装
- 注入预算管控：生文前文≤5000、各辅助行为前文≤1000、成长尾 10 条——降本 5~25%
- 上下文预算条：估算 + 发送后真实 usage 双轨显示
- 缓存分区：稳定段前置提升命中率（检测 v8.6 同步优化）
- 检测稳定段前置（v8.6）：固定规则前置、变段垫底——重复检测命中缓存
- 审稿参数模式（v8.6）：思考/参数两模式互斥，温度/Top-p/惩罚可调

**数据与体验**
- 💾 本地存储 + 一键备份/恢复（兼容 2.6~8.6 存档）；导出 TXT/JSON
- 📊 写作统计看板、日志、峰谷计价、页签提醒、隐藏模式
- 🔒 生成期编辑锁定，杜绝数据覆盖
- 🗺️ 关系图角色右键高亮（v8.6）：白底黑字标记，刷新保持
